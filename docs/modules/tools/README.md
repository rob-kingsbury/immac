# Tools Modules

The editor you write in and the browser you debug in. Set the first one up once; come back to the second every time something does not look right.

- [Setting Up Your Development Environment](/modules/tools/vscode/README.md). Installing and configuring the editor, Git, and the extensions you will actually use.
- [Your Editor Catches Some of This Before You Even Save](/modules/tools/vscode/editor-diagnostics.md). Mistakes your editor catches while you type, before anything else has run.
- [Browser Developer Tools](/modules/tools/browsers/README.md). Developer tools as a diagnostic instrument, from opening a panel to a routine you can repeat.
- [Developer Tools for Debugging](/modules/tools/browsers/devtools.md). Finding your way around the panels, and reading a console error down to the file and line.
- [Inspecting CSS Rules](/modules/tools/browsers/inspecting-css-rules.md). Reading the Styles panel to see which rule won and which was struck out.
- [Inspecting the Box Model](/modules/tools/browsers/inspecting-the-box-model.md). The box diagram, and the three questions it answers in seconds.
- [Debugging CSS Conflicts](/modules/tools/browsers/debugging-css-conflicts.md). A five-step routine for a rule that refuses to apply.
- [Inspecting a Grid](/modules/tools/browsers/inspecting-a-grid.md). The grid overlay, with every track drawn and every line numbered.
- [Inspecting Variables](/modules/tools/browsers/inspecting-variables.md). Checking whether a custom property resolved, since a misspelled one fails silently.
- [Testing Responsive Work](/modules/tools/browsers/testing-responsive-work.md). Four ways to test a responsive layout, in increasing order of trustworthiness.
- [Diagnosing Rendering Problems](/modules/tools/browsers/diagnosing-rendering-problems.md). A six-step order of checks for anything that looks wrong on screen.
