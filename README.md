# IMM Web Courses

Course content site for Algonquin College's Interactive Media Management
(IMM) program — **MTM1511 (Web Components)** and **MTM1544 (Web Styles)**.

Organized as a set of topic-based lesson modules shared across both
courses, with each course providing its own overview, weekly content, and
resources.

This site is a reference resource only. Assignments and submissions are
handled through Brightspace and student GitHub repos, not here.

## Starter repositories

Some assignments hand students a starting point rather than a blank folder. Each one is a
**GitHub template repository**, so a student clicks "Use this template", ends up owning their own
copy, turns Pages on, and submits that Pages URL. No GitHub Classroom is involved.

| Starter | Used by | Repository |
|---|---|---|
| Mountain Trail Guide | MTM1544, Week 1 Assignment: Styling the Starter Page | [mtm1544-week01-starter](https://github.com/rob-kingsbury/mtm1544-week01-starter) |

These live under the same account as this site and are expected to move with the courses. If the
program takes them over, move the repositories, keep the template flag and Pages turned on, then
update three places: the link in this table, the link in the assignment markdown in
`imm-ac-assessments`, and the assignment description in the Brightspace shell, which does not
update itself from the package once imported.
